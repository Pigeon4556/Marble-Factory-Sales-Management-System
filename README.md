# 🏛️ MarblePro – Marble Factory Management System

**MarblePro** is a web-based Marble Factory Management System developed for **AL Madina Marble Factory, Rawalpindi**. It provides a centralized dashboard to manage daily factory sales, marble inventory, customer transactions, stock movements, and business performance.

The system is designed to simplify factory operations, reduce manual record-keeping, and provide useful insights into sales and inventory.

## ✨ Features

### 📊 Dashboard
- Monthly revenue overview.
- Monthly profit calculations.
- Total sales transactions.
- Inventory item statistics.
- Low-stock alerts.
- Monthly sales revenue visualization.
- Sales distribution by marble type.
- Recent transaction overview.

### 🧾 Sales & Receipt Management
- Create new customer sales receipts.
- Automatically generate receipt numbers.
- Add multiple marble products to a receipt.
- Record customer name, phone number, and delivery address.
- Calculate subtotals and discounts.
- Select payment methods.
- Track payment status (Paid, Partial, Pending).
- Print customer receipts.

### 📦 Inventory Management
- Add new marble types.
- Update existing inventory.
- Manage marble SKU codes.
- Track marble quantities in square feet.
- Set selling prices and purchase costs.
- Configure low-stock thresholds.
- Store marble sizes, colors, and descriptions.
- Monitor stock availability.

### 📈 Stock Movement Tracking
- Record incoming stock.
- Automatically deduct stock after sales.
- Maintain a stock movement log.
- Track stock quantities and transaction references.

### 📉 Business Analytics
- All-time revenue calculations.
- All-time profit calculations.
- Total square feet of marble sold.
- Sales performance by marble type.
- Revenue comparison by marble type.
- Profit and profit-margin analysis.

### 💾 Data Management
- Automatically save application data using browser LocalStorage.
- Export business data as JSON backup.
- Import previously exported backup files.
- Restore inventory and sales records.

## 🛠️ Technologies Used

- **HTML5** – Application structure.
- **CSS3** – Styling and responsive dashboard interface.
- **JavaScript** – Application functionality and business logic.
- **LocalStorage** – Browser-based data persistence.
- **SVG** – Data visualization and charts.
- **Google Fonts** – Typography and visual presentation.

## 🚀 Installation & Usage

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/marble-factory-management-system.git
   ```

2. Open the project folder.

3. Open `index.html` in your web browser.

4. Start managing marble inventory, sales, receipts, and analytics.
